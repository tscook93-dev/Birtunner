# Credits

All code and art in this repository were made for Birtunner. No third-party sprites, sounds, fonts, or trademarks are included.

## Art

Drawn for this project with `tools/make_art.py` (original pixel and button art, no imported images):

- `art/bit_sheet.png` — Bit, the runner (idle, run, and jump frames).
- `art/btn_left.png`, `art/btn_left_down.png` — left control.
- `art/btn_right.png`, `art/btn_right_down.png` — right control.
- `art/btn_jump.png`, `art/btn_jump_down.png` — jump control.
- `art/splash.png` — boot splash.
- `icon.png` — application icon.

The "MOTION BAY" label uses Godot Engine's built-in default font, which ships with the engine.
